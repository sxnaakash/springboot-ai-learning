# Spring Security + JWT Implementation Notes

## Objective

Secure Spring Boot REST APIs using JWT Authentication.

---

# Authentication Flow

## Step 1 - Login

Request

POST /auth/login

```json
{
  "username": "akash",
  "password": "password123"
}
```

Response

```text
eyJhbGciOiJIUzI1NiJ9...
```

JWT token is generated by JwtService.

---

## Step 2 - Access Protected APIs

Request

GET /employees

```http
Authorization: Bearer <jwt-token>
```

Flow

Client
↓
JwtAuthenticationFilter
↓
JwtService.extractUsername()
↓
SecurityContextHolder
↓
EmployeeController
↓
200 OK

# Classes and Responsibilities

## SecurityConfig

Purpose

* Defines security rules
* Registers JWT filter
* Configures public and protected APIs

Example

```java
.requestMatchers("/auth/**").permitAll()
.anyRequest().authenticated()
```

Meaning

| Endpoint    | Access    |
| ----------- | --------- |
| /auth/login | Public    |
| /employees  | Protected |

## JwtService

Purpose

Responsible for JWT operations.

### generateToken()

Creates JWT token.

```java
generateToken(username)
```

Stores

```json
{
  "sub":"akash"
}
```

inside token.

---

### extractUsername()

Reads username from JWT.

Example

```java
extractUsername(token)
```

Returns

```text
akash
```

---

### validateToken()

Checks

* Signature valid
* Token not modified
* Token not expired

# JWT Concepts

## subject(username)

Purpose

Stores user identity.

Example

```java
.subject("akash")
```

Creates

```json
{
  "sub":"akash"
}
```

Meaning

Token belongs to user Akash.

---

## signWith(key)

Purpose

Digitally signs token.

Example

```java
.signWith(secretKey)
```

Protects against

* Token tampering
* Fake token creation

---

# JwtAuthenticationFilter

Extends

```java
OncePerRequestFilter
```

Purpose

Intercept every request and authenticate user.

Flow

Read Authorization Header
↓
Extract JWT
↓
Extract Username
↓
Create Authentication Object
↓
Store in SecurityContextHolder
↓
Continue Request

---

# Filter Scenarios

## No Token

Request

```http
GET /employees
```

Result

Filter skips authentication.

Spring Security returns:

```http
401 Unauthorized
```

---

## Valid Token

Request

```http
Authorization: Bearer token
```

Result

User authenticated.

```http
200 OK
```

---

## Invalid Token

Request

```http
Authorization: Bearer invalid-token
```

Result

Authentication not created.

```http
401 Unauthorized
```

---

# SecurityContextHolder

Purpose

Stores authenticated user for current request.

Most Important Line

```java
SecurityContextHolder
    .getContext()
    .setAuthentication(authentication);
```

Meaning

```text
Current User = akash
Authenticated = true
```

Without this line:

```http
401 Unauthorized
```

---

# UsernamePasswordAuthenticationToken

Purpose

Represents authenticated user.

Example

```java
new UsernamePasswordAuthenticationToken(
    username,
    null,
    Collections.emptyList()
);
```

Think of it as:

```text
Authenticated User Card
```

---

# Authentication vs Authorization

Authentication

Question:

```text
Who are you?
```

Example

```text
akash
password123
```

---

Authorization

Question:

```text
What are you allowed to do?
```

Example

```text
USER
ADMIN
```

---

# JWT Structure

```text
Header.Payload.Signature
```

Example

```text
eyJhbGciOi...
.
eyJzdWIiOiJha2FzaA...
.
signature
```

Header

Algorithm information.

Payload

User information.

Signature

Generated using secret key.
